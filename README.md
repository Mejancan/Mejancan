# Ultimate Digital Marketing Platform

An end-to-end AI operating system for agencies, freelancers, and brands to plan strategy, generate content, orchestrate scheduling, manage inboxes, and report on performance from a single workspace.

## Repository layout

```
/apps
  /backend     NestJS API + domain modules (auth, clients, content, insights, inbox, SEO, scheduling)
  /frontend    Next.js 15 dashboard (App Router, Tailwind UI)
/docs
  architecture.md   High-level system blueprint, modules, and MVP scope
```

## Getting started

### Prerequisites
- Node.js 18+
- npm 10+

### Install dependencies
```bash
cd apps/backend && npm install
cd ../frontend && npm install
```

### Run the backend API
```bash
cd apps/backend
npm run start:dev
```
The NestJS server exposes placeholder routes for:
- `GET /auth/status`, `POST /auth/integrations`
- `GET/POST /clients`
- `GET /content/templates`, `POST /content/autopilot`
- `GET /scheduling/optimal-slots`, `POST /scheduling/queue`
- `GET /inbox/threads`, `PATCH /inbox/threads/assign`, `POST /inbox/reply`
- `GET /analytics/overview`, `GET /analytics/recommendations`
- `POST /seo/blogs`, `POST /seo/blogs/syndicate`

### Run the frontend dashboard
```bash
cd apps/frontend
npm run dev
```
Open `http://localhost:3000` to explore the Autopilot calendar, strategy builder, analytics pulse, inbox preview, signature add-ons, and pricing tiers.
